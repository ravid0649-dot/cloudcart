Recommended CPU Limit: 0.25 CPU
Recommended Memory Limit: 128 MB

Explanation:
The recommendation is based on observed peak CPU and memory usage.
A safety buffer is added so containers have enough resources during load.
API Gateway receives slightly higher resources because all requests pass through it.
Product, Cart, and Order services are lightweight, so they are assigned smaller limits.
